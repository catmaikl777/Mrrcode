# MrrCode Studio

Браузерная студия языка MrrCode: редактор, PNG- и звуковые ресурсы, сцена 800×450, справка, история проекта и сборка автономной HTML-игры.

## Запуск студии

Открой папку в локальном веб-сервере, например `py -3 -m http.server 8000`, затем открой показанный адрес. Установка зависимостей не нужна.

## Главный файл

По умолчанию точка входа — `main.mrr`. Во вкладке «Файлы» после кнопки «Переименовать» доступна «Сделать главным». Она назначает исходник точкой входа, не переименовывая его и не меняя код. Открытый в редакторе файл и главный файл могут различаться.

«Запуск», отладка и HTML-сборка используют выбранный главный файл. Обработчики `start`, `update`, `pointerDown`, `pointerMove`, `pointerUp` объявляются в нём или импортируются. Выбор хранится в `entryFile` проекта: локальное сохранение, история, JSON и ZIP. В старых проектах без этого поля используется `main.mrr`, иначе первый имеющийся файл; для пустого проекта создаётся стандартный `main.mrr`. Пустой существующий исходник не заменяется шаблоном. Главный файл защищён от удаления; переименование сохраняет назначение.

## PNG и отражение

Имена функций регистрозависимы: `sprite`, `spriteAnim` (не `Sprite`). Поддерживаются имена ресурсов с `.png` и без расширения.

```mrr
sprite(name, x, y, w?, h?, flipX?, flipY?);
spriteAnim(name, x, y, w?, h?, frameW?, frameH?, fps?, flipX?, flipY?);
```

Знак `?` в справке обозначает необязательный аргумент, в коде его не пишут. `flipX` — отражение по горизонтали, `flipY` — по вертикали. Значения `true`/`false`, по умолчанию оба `false`. Аргументы позиционные: для отражения спрайта в исходном размере можно передать `null, null` вместо `w, h`.

Если у PNG во вкладке «Файлы» задана сетка кадров (кнопка «⚙», например `4×2`), то `frameW` и `frameH` у `spriteAnim` можно не указывать: движок сам делит ширину и высоту PNG на число колонок и строк. Явные `frameW/frameH` имеют приоритет; `w`/`h` по умолчанию 32, `fps` — 8. То же правило действует в HTML-сборке.

Отражение выполняется внутри прямоугольника вывода без изменения его левого верхнего угла `(x,y)`, размера и смещения камеры. Для анимации отражается текущий кадр, а не весь лист; порядок кадров не меняется. Остальное рисование не отражается. Старые вызовы совместимы.

```mrr
function update(dt) {
    sprite("hero.png", 100, 100, 32, 32, true, false);
    spriteAnim("walk.png", 320, 150, 64, 32, 32, 32, 8, false, true);
}
```

`w/h` задают размер вывода одного кадра; `frameW/frameH` — размер исходного кадра в PNG. Лист 64×32 с кадрами 32×32 перебирается слева направо каждые 125 мс при 8 кадрах/с, затем цикл повторяется. Многострочные листы перебираются по строкам. Отсчёт идёт с запуска игры; сглаживание отключено. Для оригинального размера кадра укажи `w=32, h=32`.

Поведение отражения одинаково в студии и HTML-сборке. Основная документация и спецификация API доступны внутри студии: «Справка», «Инструменты → Шпаргалка», `MRRCODE_AI_SPEC`, `MRRCODE_API_REGISTRY`.

## Звуки

Во вкладке «Файлы» есть импорт звука (`.wav`, `.mp3`, `.ogg`). Импортированный файл становится ресурсом с именем файла без расширения:

```mrr
function pointerDown(x, y) {
    playSound("coin");      // импортированный звук, расширение можно опустить
    playTone(660, 0.12, 0.08); // синтезированный тон, без файла
}
```

`playSound(name)` проигрывает звук с начала; `playTone(frequency, duration, volume?)` синтезирует тон. Первый звук стоит запускать из действия пользователя (касание/клик), иначе браузер может заблокировать автовоспроизведение. Звуки входят в экспорт проекта и в автономную HTML-сборку.

## Графика, камера, звук и сцена: 40 новых функций

- **Трансформации:** `pushMatrix`, `popMatrix`, `translate`, `rotate`, `scale`, `resetMatrix`, `setAlpha`. Матрица сбрасывается каждый кадр; `translate` автоматически учитывает `camera()`.
- **Тинт и текст:** `spriteTint(name,x,y,w?,h?,color?,alpha?)`, `textWrap(text,x,y,maxWidth,color?,size?)`.
- **Фигуры и эффекты:** `polygon(points,color?)`, `gradient(x,y,w,h,c1,c2,vertical?)`, `setShadow(blur,color?)`, `screenshot()`.
- **Камера:** `cameraFollow(object,smoothness?)`, `cameraZoom(zoom)`, `shake(power,duration?)`.
- **Частицы и анимации:** `particles(x,y,count,options?)`, `tween(object,property,target,duration,easing?)`, `cancelTween(id)`.
- **Звук:** каналы `music`/`sfx` через `setChannelVolume`, `playMusic(name,loop?,volume?)`, `stopMusic(fade?)`, `playSoundAt(name,x,y?)`; при сворачивании вкладки звук ставится на паузу.
- **Сцена:** `spawnObject(type,x,y,props?)`, `destroyObject(target)`, `cloneObject(target)`, `setTag(target,tag)`, `objectsWithTag(tag)`.
- **Сохранения:** `saveVersion`/`loadVersion` (версия не совпала — значение по умолчанию), `saveAuto`/`loadAuto`.
- **Данные:** `forEach`, `filter`, `reduce`, `mapArray`, `safeCall`, `poolCreate`, `poolTake`, `poolPut`.

Язык: добавлены `for (let key in object)`, метки `outer: for (…) { break outer; }`, параметры по умолчанию `function f(a = 1)`, записи `===`/`!==` как синонимы `==`/`!=`, а сообщения об ошибках теперь показывают стек вызовов.

`randomSeed(seed)` включает воспроизводимый ГПСЧ: после него `random()`, `rand()` и `randomInt()` дают одинаковую последовательность при одном и том же seed. Без вызова `randomSeed` используется `Math.random()`.

`saveSlot`/`loadSlot` пишут в `localStorage` под префиксом `mrr-slot:` и не пересекаются с `save`/`load`. `spriteAnimFrame` рисует кадр по индексу без автопрокрутки и учитывает сетку PNG, заданную во вкладке «Файлы».

## Циклы и выбор

Кроме `while` и двух видов `for`, язык поддерживает:

```mrr
do {
    i += 1;
} while (i < 10);

switch (state) {
    case "menu":
        drawMenu();
        break;
    case "game":
        drawGame();
        break;
    default:
        drawPause();
}

for (let index, item of items) {
    text(index + ": " + item, 10, 20 + index * 18);
}
```

`switch` сравнивает значения строго (`===`), допускает `default` в любом месте и «проваливание» в следующий `case`, если нет `break`. `break` внутри `switch` в цикле выходит только из `switch`. `for (let index, item of array)` даёт индекс и значение; без второго имени работает обычный `for (let item of array)`.

Классов в MrrCode нет: `class`, `new` и `this` не поддерживаются. Вместо класса — объект и функции, принимающие его первым аргументом:

```mrr
let fish = {x: 100, y: 100, vx: 20};

function moveFish(f, dt) {
    f.x += f.vx * dt;
}
```

Пространства имён JavaScript (`Math`, `console`, `JSON`, `Object`, `Array`, `String`, `Number`, `Date`, `document`, `window`, `navigator`, `localStorage`) недоступны. Пиши `floor(x)`, `random()`, `print(x)`, `toString(x)`, а число π — `3.141592653589793`. Студия автоматически заменяет точные эквиваленты (`Math.floor` → `floor`, `Math.PI` → число, `console.log` → `print`) и сообщает об этом в чате.

## Ввод, таймеры и HUD

Клавиатура: `keyDown(code)`, `keyPressed(code)`, `keyReleased(code)`; код — как в `KeyboardEvent.code` (`"ArrowLeft"`, `"Space"`, `"KeyA"`). Геймпад: `gamepadButton(index)`, `gamepadAxis(index)`.

Таймеры: `after(seconds, callback)`, `every(seconds, callback)`, `cancelTimer(id)`; кадры: `fps()`, `frameCount()`. Сцена: `objects()`; сохранения: `deleteSave(key)`, `deleteSlot(slot)`.

Цвет: `hsl`, `mixColor`, `withAlpha`. Анимация: `easeInQuad`, `easeOutQuad`, `easeInOutQuad`, `easeOutCubic`, `easeOutBack`, `easeOutElastic`, `lerpAngle`, `normalizeAngle`, `smoothstep`. Случайность: `pick`, `shuffle`, `chance` (учитывают `randomSeed`). Коллизии и HUD: `circleCircle`, `pointInCircle`, `bar`, `textRight`. Звук: `setVolume`.

```mrr
function update(dt) {
    if (keyDown("ArrowLeft")) x -= 200 * dt;
    if (keyPressed("Space")) jump();
    bar(20, 20, 120, 10, health / maxHealth);
    textRight("HP " + health, 780, 20);
}
```

## Темы и оформление

Тем четыре: «Ночь» (по умолчанию), «Бумага», «Полночь» и «Мята». Переключение — кнопкой с иконкой луны в шапке; выбор запоминается в браузере.

Цвета панелей, шапки, рельса, вкладок, консоли, палитры команд и кнопок задаются CSS-токенами в слое `<style id="mrr-theme-surfaces">`, поэтому каждая тема красит свои поверхности и не наследует цвета первой. Второй слой, `<style id="mrr-refinement">`, отвечает за сетку, отступы, состояния наведения и мобильные цели касания (44px). Если добавляешь новый цветной элемент, заведи токен сразу в четырёх блоках: `:root`, `body.mrr-midnight`, `body.mrr-light`, `body.mrr-light.mrr-mist`.

На широком экране (от 1180px) вкладки уезжают в левый рельс шириной 78px, а панель проекта растягивается по высоте — от строки инструментов до статус-строки.

Кое-что кошачье: ушки у логотипа, лапки у заголовков разделов и консоли, лапка-водяной знак и `ฅ^•ﻌ•^ฅ` в подвале панели проекта. Это только CSS-декор, на работу студии он не влияет.

## ИИ-агент (LLM7)

Кнопка «ИИ» открывает агента, который создаёт и правит файлы `.mrr` и объекты сцены. По умолчанию настроен LLM7:

- Base URL: `https://api.llm7.io/v1`;
- модель: `gpt-5.6-luna` (в списке также `deepseek-v4.1-flash`, `gemini-3-flash`, `kimi-k2.7-code`, `codestral-latest`, `glm-5.2`);
- токен: бесплатный, с [dash.llm7.io](https://dash.llm7.io), вставляется в поле «Токен».

Без токена LLM7 отвечает `401`: анонимный доступ закрыт. С бесплатным токеном действует суточный лимит (около 100 тыс. токенов на подходящих моделях); при `429` агент просит подождать. Токен хранится только в `localStorage` браузера и уходит напрямую на `api.llm7.io`; CORS у сервиса открыт.

К каждому запросу автоматически добавляется требование «ОБЯЗАТЕЛЬНО ПРИМЕНИ ИЗМЕНЕНИЯ В ФАЙЛЫ»: модель должна вернуть полный текст изменённых файлов в `files` (и объекты сцены в `scene`), а не только объяснение. Если пользователь уже написал эту фразу сам, дубликат не добавляется.

Перед валидацией код проходит линтер JS-конструкций: `class/new/this/=>/try/catch/var`, `Math/console/JSON` и другие пространства имён, методы через точку, `.length`, `?.`, `??`, `...`. Точные эквиваленты заменяются автоматически (`Math.floor` → `floor`, `Math.PI` → число, `console.log` → `print`, `===` → `==`), остальное уходит в автоисправление — до 3 попыток. В промпт добавлены чек-лист и два эталонных примера кода; для генерации лучше выбирать пресет «LLM7 Code» (`kimi-k2.7-code`).

В оба системных промпта добавлен полный канонический список всех 178 функций с сигнатурами и карта частых выдуманных имён (`angle`, `textHeight`, `startTime`, `sceneObjects`, `createRect`, `deleteObject`, `tagObject`, `autoSave`, `createPool`, `deleteSaveSlot`, `suspendAudio`, `resumeAudio` и др.) с готовой заменой. Модель обязана использовать только имена из списка; если функции нет — сказать об этом и предложить ближайшую существующую.

Пресеты OpenAI, Anthropic, OpenRouter, Ollama и LM Studio остаются доступны; для локальных серверов ключ не нужен. Стриминг ответа включается флажком.

## Производительность

- Подсветка кода кэшируется по тексту и обновляется раз в кадр, а не на каждое нажатие; миникарта хранит готовую карту в offscreen-canvas.
- Позиция каретки и списки функций/переменных/импортов не пересчитываются без изменений текста.
- Автосейв и снимки истории срабатывают только при реальном изменении проекта.
- Игровой цикл кэширует шрифты и ширины текста, консоль обновляет прокрутку раз в кадр.
- Тяжёлые панели (палитра, списки, превью) строятся после первого кадра через `requestIdleCallback`.

## Полный справочник API

Сгенерировано из `MRRCODE_API_REGISTRY`: 178 функций и 5 событий. Полные описания с сигнатурами — «Справка» → раздел 35; здесь тот же список для поиска по репозиторию.

### События жизненного цикла

- `function pointerDown(x, y)` — Событие: палец коснулся игрового поля. x, y — координаты 0..800 / 0..450. Срабатывает для каждого пальца (мультитач).
- `function pointerMove(x, y)` — Событие: палец движется по игровому полю.
- `function pointerUp(x, y)` — Событие: палец отпущен.
- `function start()` — Вызывается один раз при нажатии «Запуск».
- `function update(dt)` — Вызывается каждый кадр. dt — секунды с прошлого кадра.

### Ввод и касания

- `gamepadAxis(index)` — Значение оси геймпада от −1 до 1 (0 — левый стик по X, 1 — по Y).
- `gamepadButton(index)` — true, если кнопка геймпада нажата (0 — A/крест); состояние опрашивается раз в кадр.
- `keyDown(code)` — true, пока клавиша удерживается; код как в KeyboardEvent.code: «ArrowLeft», «Space», «KeyA».
- `keyPressed(code)` — true только в кадре, когда клавиша была нажата.
- `keyReleased(code)` — true только в кадре, когда клавиша была отпущена.
- `pointerDownNow()` — true, пока хоть один палец удерживает игровое поле.
- `pointerX()` — X-координата последнего касания (0..800).
- `pointerY()` — Y-координата последнего касания (0..450).
- `touchCount()` — Сколько пальцев сейчас касается поля (мультитач).
- `touchX(i)` — X-координата i-го пальца (0 … touchCount()-1); для несуществующего индекса 0.
- `touchY(i)` — Y-координата i-го пальца (0 … touchCount()-1); для несуществующего индекса 0.

### Рисование

- `background(color?)` — Задаёт постоянный цвет фона игры. Вызови один раз в start(); цвет по умолчанию #0f172a. Фон заливается этим цветом в начале каждого кадра.
- `bar(x,y,w,h,value,color?,bg?)` — Полоса прогресса: фон bg и заполнение color на долю value 0…1.
- `camera(x,y)` — Задаёт смещение камеры для следующих rect/circle/line/text/sprite/spriteAnim. Для сброса вызови camera(0,0); координаты касаний не меняются.
- `cameraFollow(object,smoothness?)` — Плавно ведёт камеру за объектом; smoothness 0…1 (по умолчанию 0.12).
- `cameraZoom(zoom)` — Масштаб камеры 0.1…10 (1 — без масштаба); возвращает установленное значение.
- `circle(x, y, r, color?)` — Круг с центром (x, y) и радиусом r. Цвет по умолчанию #70d6ff.
- `clear(color?)` — Очищает текущий кадр и заливает его цветом color (по умолчанию "#0f172a"). Для постоянного фона используй background(color?).
- `gradient(x,y,w,h,color1,color2,vertical?)` — Заливает прямоугольник линейным градиентом; vertical=true сверху вниз.
- `hsl(h,s,l,a?)` — CSS-цвет hsla(h, s%, l%, a); h в градусах, s/l в процентах, a по умолчанию 1.
- `line(x1, y1, x2, y2, color?, width?)` — Линия из (x1, y1) в (x2, y2). Цвет по умолчанию #ffffff, width — толщина (по умолчанию 2).
- `mixColor(colorA,colorB,t)` — Смешивает два цвета (#rgb, #rrggbb или rgb()) с коэффициентом t 0…1.
- `particles(x,y,count,options?)` — Создаёт count частиц; options: speed, life, size, color, gravity, spread; возвращает число живых частиц.
- `polygon(points,color?)` — Заливает многоугольник; points — плоский массив [x1,y1,x2,y2,x3,y3,…].
- `popMatrix()` — Восстанавливает матрицу, сохранённую pushMatrix().
- `pushMatrix()` — Сохраняет текущую матрицу рисования (как ctx.save).
- `rect(x, y, w, h, color?)` — Прямоугольник: левый верхний угол (x, y), размер w×h. Цвет по умолчанию #70d6ff.
- `resetMatrix()` — Сбрасывает матрицу рисования и ручные трансформации.
- `rgba(r, g, b, a?)` — Возвращает CSS-цвет rgba() из красного, зелёного, синего и альфа-канала. a по умолчанию 1.
- `rotate(angle)` — Поворачивает систему координат на angle радиан вокруг текущего начала.
- `roundedRect(x,y,w,h,r,color?)` — Рисует скруглённый прямоугольник; радиус ограничивается половиной меньшей стороны.
- `scale(x,y?)` — Масштабирует последующее рисование; y по умолчанию равен x.
- `screenshot()` — Возвращает PNG-снимок игрового поля как dataURL или null.
- `setAlpha(alpha)` — Задаёт прозрачность последующего рисования 0…1; возвращает значение.
- `setShadow(blur,color?)` — Включает тень для последующего рисования; blur 0 выключает.
- `shake(power,duration?)` — Тряска камеры силой power на duration секунд (по умолчанию 0.35).
- `sprite(name, x, y, w?, h?, flipX?, flipY?)` — Рисует PNG с .png или без расширения; w/h по умолчанию исходные; flipX/flipY отражают по горизонтали/вертикали, false по умолчанию, без смещения якоря.
- `spriteAnim(name,x,y,w?,h?,frameW?,frameH?,fps?,flipX?,flipY?)` — Циклически переключает кадры PNG слева направо, затем сверху вниз, с запуска игры. w/h — размер вывода кадра (по умолчанию 32×32); frameW/frameH — размер кадра в PNG (можно не указывать при заданной сетке кадров); fps — кадров/с (по умолчанию 8). Имя с .png или без. flipX/flipY отражают текущий кадр, false по умолчанию; порядок кадров и (x,y) не меняются.
- `spriteAnimFrame(name,x,y,w,h,frame,flipX?,flipY?)` — Рисует конкретный кадр спрайт-листа по индексу, без автопрокрутки; сетка берётся из метаданных спрайта.
- `spriteTint(name,x,y,w?,h?,color?,alpha?)` — Рисует PNG, закрашенный цветом color с прозрачностью alpha; w/h по умолчанию 32.
- `text(value, x, y, color?, size?)` — Текст в точке (x, y). Цвет по умолчанию #ffffff, size — размер шрифта (по умолчанию 16).
- `textCentered(text,x,y,color?,size?)` — Рисует текст с центрированием по x; цвет #ffffff, размер 16.
- `textRight(text,x,y,color?,size?)` — Рисует текст с выравниванием по правому краю в точке x.
- `textWidth(text,size?)` — Ширина текста в пикселях при заданном размере шрифта; размер по умолчанию 16.
- `textWrap(text,x,y,maxWidth,color?,size?)` — Рисует текст с переносом слов по maxWidth; возвращает число строк.
- `translate(x,y)` — Смещает начало координат для последующего рисования; камера учитывается автоматически.
- `withAlpha(color,alpha)` — Возвращает rgba(...) для цвета #rgb/#rrggbb/rgb() с заданной прозрачностью.
- `worldX(screenX)` — Переводит экранную координату x в мировую с учётом camera().
- `worldY(screenY)` — Переводит экранную координату y в мировую с учётом camera().

### Экран и датчики

- `gameHeight()` — Логическая высота игровой сцены: 450 единиц, независимо от размера устройства.
- `gameWidth()` — Логическая ширина игровой сцены: 800 единиц, независимо от размера устройства.
- `isPortrait()` — true, если высота видимой области не меньше ширины.
- `orientationAngle()` — Угол поворота экрана в градусах (обычно 0, 90, 180 или 270).
- `requestMotion()` — Запрашивает разрешение на датчик ориентации там, где браузер этого требует. Возвращает Promise<boolean>. Вызывай после касания/нажатия.
- `screenHeight()` — Высота видимой области браузера в CSS-пикселях, включая полноэкранный режим. Для координат сцены используй gameHeight().
- `screenWidth()` — Ширина видимой области браузера в CSS-пикселях, включая полноэкранный режим. Для координат сцены используй gameWidth().
- `tiltX()` — Наклон телефона влево/вправо (gamma, обычно −90…90°). Нужны поддержка устройства и разрешение.
- `tiltY()` — Наклон телефона вперёд/назад (beta, обычно −180…180°). Нужны поддержка устройства и разрешение.
- `tiltZ()` — Ориентация вокруг вертикальной оси (alpha, 0…360°; не гарантирует компасный север).

### Физика и столкновения

- `circleCircle(x1,y1,x2,y2,r1,r2)` — true, если два круга пересекаются или касаются.
- `moveBody(body,dt,gravity)` — Обновляет объект {x,y,vx,vy}: сначала vy += gravity*dt, затем x/y обновляются по vx/vy. dt ограничивается 0..0.1 сек. Меняет объект и возвращает его.
- `overlapCircle(cx,cy,r,x,y,w,h)` — true, если круг пересекается с прямоугольником.
- `overlapRect(ax,ay,aw,ah,bx,by,bw,bh)` — Проверяет пересечение двух осевых прямоугольников (x,y,w,h). Касание только краями не считается пересечением; возвращает true/false.
- `pointInCircle(px,py,cx,cy,r)` — true, если точка внутри круга, включая границу.
- `pointInRect(px,py,x,y,w,h)` — true, если точка лежит внутри прямоугольника, включая границы.

### Сцена и объекты

- `cloneObject(target)` — Создаёт копию объекта сцены с новым id и именем; возвращает копию.
- `destroyObject(target)` — Удаляет объект сцены по ссылке или имени; true, если удалён.
- `object(name)` — Возвращает объект сцены по имени (вкладка «Сцена») или null, если объекта нет. Свойства можно менять из кода: x, y, w, h, r, color, text, size.
- `objects()` — Массив живых объектов сцены; элементы можно менять, как через object(name).
- `objectsWithTag(tag)` — Массив объектов сцены с данным тегом.
- `setTag(target,tag)` — Ставит тег объекту сцены; возвращает объект.
- `spawnObject(type,x,y,props?)` — Создаёт объект сцены rect, circle или text и возвращает его; props: w,h,r,text,size,color,name.

### Математика и случайность

- `abs(x)` — Модуль числа.
- `angleDiff(a,b)` — Кратчайшая разница углов b−a в диапазоне −π…π с учётом перехода через 360°.
- `angleTo(x1,y1,x2,y2)` — Угол направления на точку (x2,y2) в радианах, как Math.atan2(dy,dx).
- `approach(value,target,step)` — Двигает value к target на step, не перескакивая target.
- `atan2(y, x)` — Угол в радианах по координатам y и x; результат от -π до π.
- `ceil(x)` — Округление вверх.
- `chance(p)` — true с вероятностью p (0…1); учитывает randomSeed.
- `clamp(value, min, max)` — Ограничивает значение рамками min..max.
- `cos(a)` — Косинус угла в радианах.
- `distance(x1,y1,x2,y2)` — Евклидово расстояние между двумя точками.
- `distanceSq(x1,y1,x2,y2)` — Квадрат расстояния между точками; быстрее distance, удобен для сравнений.
- `easeInOutQuad(t)` — Квадратичное ускорение-торможение.
- `easeInQuad(t)` — Квадратичное ускорение t²; t ограничивается диапазоном 0…1.
- `easeOutBack(t)` — Торможение с проскоком назад (overshoot).
- `easeOutCubic(t)` — Кубическое торможение 1−(1−t)³.
- `easeOutElastic(t)` — Упругое затухание (elastic).
- `easeOutQuad(t)` — Квадратичное торможение t(2−t).
- `floor(x)` — Округление вниз.
- `lerp(a, b, t)` — Линейно смешивает a и b по t от 0 до 1.
- `lerpAngle(a,b,t)` — Интерполирует угол по кратчайшей дуге; t 0…1.
- `map(value, inMin, inMax, outMin, outMax)` — Переносит число из одного диапазона в другой.
- `max(a, b)` — Большее из двух чисел.
- `min(a, b)` — Меньшее из двух чисел.
- `normalizeAngle(a)` — Приводит угол к диапазону −π…π.
- `pick(array)` — Случайный элемент массива (учитывает randomSeed); null для пустого массива.
- `pow(a, b)` — Возводит a в степень b. Также доступен оператор **.
- `rand(min, max)` — Случайное число от min до max.
- `random()` — Случайное число от 0 до 1.
- `randomInt(min, max)` — Случайное целое в диапазоне включительно.
- `randomSeed(seed)` — Включает воспроизводимый ГПСЧ с данным seed; влияет на random(), rand() и randomInt().
- `round(x)` — Округление до ближайшего целого.
- `shuffle(array)` — Возвращает перетасованную копию массива (учитывает randomSeed).
- `sign(x)` — Возвращает -1, 0 или 1.
- `sin(a)` — Синус угла в радианах.
- `smoothstep(edge0,edge1,x)` — Плавная интерполяция 0…1 с нулевой производной на краях.
- `sqrt(x)` — Квадратный корень.
- `wrap(value,min,max)` — Заворачивает значение в диапазон [min,max): позиция за краем возвращается с другой стороны.

### Массивы и данные

- `clone(value)` — Глубокая копия массива или объекта; примитивы возвращаются как есть.
- `contains(value, part)` — Проверяет наличие подстроки в строке или элемента в массиве.
- `filter(array,callback)` — Возвращает новый массив элементов, для которых callback(value,index) вернул истину.
- `forEach(array,callback)` — Вызывает callback(value,index) для каждого элемента массива; ничего не возвращает.
- `has(obj,key)` — true, если ключ (или индекс) есть в объекте или массиве.
- `indexOf(array, value)` — Индекс первого точного совпадения в массиве или -1, если элемент не найден.
- `join(array, separator)` — Объединяет элементы массива в строку.
- `keys(obj)` — Массив ключей объекта или индексов массива.
- `length(value)` — Длина строки или массива, число ключей объекта. Для null и чисел возвращает 0.
- `mapArray(array,callback)` — Возвращает новый массив из результатов callback(value,index).
- `maxOf(array)` — Наибольшее число в массиве; null для пустого массива.
- `pop(array)` — Убирает и возвращает последний элемент массива.
- `push(array, value)` — Добавляет элемент в конец массива.
- `reduce(array,callback,initial?)` — Сворачивает массив: callback(acc,value,index); initial — стартовое значение.
- `removeAt(array,index)` — Удаляет элемент по индексу на месте и возвращает изменённый массив или null.
- `shift(array)` — Удаляет и возвращает первый элемент массива; массив изменяется.
- `slice(array, start, end?)` — Возвращает копию части массива от start до end (end не включается); исходный массив не меняется.
- `sortBy(array,key,desc?)` — Возвращает отсортированную копию массива по полю key; desc=true — по убыванию.
- `splice(array, start, count, ...items)` — Удаляет count элементов массива начиная с start и вставляет вместо них items. Изменяет исходный массив и возвращает удалённые элементы.
- `split(text, separator)` — Разделяет строку на массив.
- `sum(array)` — Сумма числовых элементов массива.
- `unshift(array, value)` — Добавляет value в начало массива и возвращает новую длину массива.
- `values(obj)` — Массив значений объекта или копия массива.

### Время и таймеры

- `after(seconds, callback)` — Вызывает callback один раз через seconds секунд; возвращает id для cancelTimer.
- `cancelTimer(id)` — Отменяет таймер after/every по id; true, если таймер найден.
- `cancelTween(id)` — Останавливает tween по id; true, если он был активен.
- `dt()` — Секунды с прошлого кадра (то же, что аргумент update).
- `every(seconds, callback)` — Вызывает callback каждые seconds секунд; возвращает id для cancelTimer.
- `fps()` — Сглаженная частота кадров; обновляется не чаще двух раз в секунду.
- `frameCount()` — Число кадров с начала запуска.
- `time()` — Число секунд с момента запуска игры.
- `tween(object,property,target,duration,easing?)` — Плавно меняет числовое свойство объекта к target за duration секунд; easing — имя функции сглаживания; возвращает id.

### Строки и преобразования

- `endsWith(text, suffix)` — Проверяет, заканчивается ли строка на suffix; возвращает true/false.
- `format(template,...values)` — Подставляет значения в шаблон: format("{0} + {1} = {2}",2,3,5).
- `isArray(value)` — true, если значение является массивом.
- `lower(text)` — Возвращает строку в нижнем регистре.
- `padLeft(text,length,char?)` — Дополняет строку слева до нужной длины; символ по умолчанию — пробел.
- `repeat(text,count)` — Повторяет строку count раз (не более 10000).
- `replace(text, from, to)` — Заменяет все вхождения подстроки from на to и возвращает новую строку.
- `startsWith(text, prefix)` — Проверяет, начинается ли строка с prefix; возвращает true/false.
- `toNumber(value)` — Преобразует значение в число.
- `toString(value)` — Преобразует значение в строку.
- `trim(text)` — Убирает пробельные символы в начале и конце строки.
- `typeof(value)` — Возвращает название типа строкой; массивы распознаются отдельно как "array". Для null результат соответствует правилам JavaScript и равен "object".
- `upper(text)` — Возвращает строку в верхнем регистре.

### Сохранения

- `deleteSave(key)` — Удаляет значение save(key); true при успехе.
- `deleteSlot(slot)` — Удаляет слот saveSlot; true при успехе.
- `load(key, defaultValue?)` — Загружает значение из localStorage; если ключа нет, возвращает defaultValue (по умолчанию null).
- `loadAuto(defaultValue?)` — Читает автосохранение; иначе defaultValue (null).
- `loadSlot(slot,defaultValue?)` — Читает значение слота; если слот пуст или повреждён — defaultValue (по умолчанию null).
- `loadVersion(key,version,defaultValue?)` — Читает значение, только если сохранённая версия совпадает; иначе defaultValue (null).
- `save(key, value)` — Сохраняет JSON-совместимое значение в localStorage. Возвращает true при успехе и false при ошибке.
- `saveAuto(value)` — Автосохранение значения с отметкой времени; true при успехе.
- `saveSlot(slot,value)` — Сохраняет JSON-совместимое значение в localStorage под именем слота; true при успехе.
- `saveVersion(key,value,version)` — Сохраняет значение вместе с номером версии; true при успехе.

### Звук

- `playMusic(name,loop?,volume?)` — Запускает музыку из «Файлов» с зацикливанием (по умолчанию true) и громкостью 0…1.
- `playSound(name)` — Проигрывает звук, импортированный во вкладке «Файлы»; имя — как в списке звуков, расширение можно не указывать.
- `playSoundAt(name,x,y?)` — Проигрывает звук с громкостью по расстоянию от центра камеры до точки (x,y).
- `playTone(frequency, duration, volume?)` — Проигрывает короткий синтезированный тон. Частота по умолчанию 440 Гц, длительность 0.12 с, громкость 0.08 (ограничена 0…0.25).
- `setChannelVolume(channel,volume)` — Громкость канала music или sfx 0…1; возвращает значение.
- `setVolume(v)` — Мастер-громкость playTone/playSound, 0…1; возвращает установленное значение.
- `stopMusic(fade?)` — Останавливает музыку; fade — секунды плавного затухания; true при успехе.
- `stopSound()` — Приостанавливает аудиоконтекст (suspend). Следующий playTone/playSound возобновит его.

### Консоль и проверки

- `assert(condition,message?)` — Бросает ошибку с сообщением, если condition ложно; для самопроверок в игре.
- `print(...values)` — Выводит значения в консоль.

### Утилиты

- `poolCreate(size)` — Создаёт пул из size переиспользуемых объектов.
- `poolPut(pool,object)` — Возвращает объект в пул; false, если пул заполнен.
- `poolTake(pool)` — Берёт объект из пула или null, если свободных нет.
- `safeCall(fn,args?)` — Вызывает функцию с массивом аргументов и перехватывает ошибку. Возвращает {ok:true,value} или {ok:false,error}; игра не прерывается.
