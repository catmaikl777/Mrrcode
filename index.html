Как это работает

main.mrr — точка входа: «Запуск» всегда выполняет его и открывает игру на весь экран.

Связывай файлы импортами: создай player.mrr с функцией spawnPlayer(), а в main.mrr напиши from "player" import spawnPlayer;

🤖 ИИ-агент умеет сам создавать файлы и менять сцену — кнопка «🤖 ИИ» в шапке.

Имя PNG без расширения = имя ресурса для sprite("имя", x, y, w, h). Повторный импорт того же файла заменяет спрайт (без дубликатов).

Данные хранятся в памяти страницы — экспортируй проект (.json), чтобы не потерять их.

1Как устроен проект 🐾

Игра — запущенный на весь экран устройства экран. Код — логика на MrrCode. Сцена — прямоугольники, круги и текстовые объекты. Файлы — код и PNG-спрайты. 🤖 ИИ — агент, который пишет код за тебя. Точка входа — main.mrr. Координаты игрового поля всегда 800×450 — движок сам масштабирует картинку под любой экран.

2Переменные и типы 🐾

let health = 100;
let title = "Моя игра";
let alive = true;
let inventory = ["ключ", "зелье"];
let stats = {speed: 120, score: 0};
const maxHealth = 100;

Используй let для изменяемого значения и const для постоянного. Поддерживаются числа, строки, boolean, null, массивы и объекты.

3Условия, циклы и функции 🐾

if (health <= 0) {
    print("Игра окончена");
} else if (health < 30) {
    print("Опасно!");
}

let i = 0;
while (i < 5) { i += 1; }

for (let n = 0; n < 3; n++) { print(n); }
for (let item of inventory) { print(item); }

function damage(amount) {
    health -= amount;
    return health;
}

Операторы: + - * / % **, сравнения == != < > <= >=, логические && || !, присваивания = += -= *= /= %=, инкремент ++ --. Вставлять их удобно кнопками на панели над редактором.

4Игровые события и управление касаниями 🐾

function start() {
    // один раз при старте
}
function update(dt) {
    // каждый кадр; dt — секунды с прошлого кадра
}
function pointerDown(x, y) { print("Палец коснулся", x, y); }
function pointerMove(x, y) { // палец движется по полю }
function pointerUp(x, y)   { // палец отпущен }

Состояние касаний прямо в update:

pointerX()        // X последнего касания (0..800)
pointerY()        // Y последнего касания (0..450)
pointerDownNow()  // true, пока палец держит поле
touchCount()      // сколько пальцев сейчас на поле
touchX(i)         // X i-го пальца (0 … touchCount()-1)
touchY(i)         // Y i-го пальца

Мультитач — кружок под каждым пальцем:

function update(dt) {
    clear("#101827");
    let i = 0;
    while (i < touchCount()) {
        circle(touchX(i), touchY(i), 30, "#70d6ff");
        i += 1;
    }
}

Клавиатуры и мыши в движке нет — только касания. Типичная схема: зоны экрана (левая треть — влево, правая — вправо, тап в центре — прыжок).

5Рисование

clear("#101827");
rect(20, 30, 120, 60, "#ff8844");
circle(220, 100, 30, "#70d6ff");
line(10, 10, 300, 200, "#ffffff", 2);
text("Привет!", 20, 140, "#ffffff", 20);

Движок сам очищает экран в начале каждого кадра — старая графика не наслаивается. Вызови clear(color) в начале update для цвета фона. Для «следа» от пальца копи точки в массив и перерисовывай их каждый кадр.

6Объекты вкладки «Сцена»

Выбери объект и задай уникальное имя name, например hero:

let hero = object("hero");

function update(dt) {
    if (pointerDownNow()) {
        hero.x = pointerX() - 32;   // объект идёт за пальцем
        hero.y = pointerY() - 32;
    }
}

Прямоугольник: x, y, w, h, color; круг: x, y, r, color; текст: x, y, text, size, color. Объекты сцены рисуются поверх игрового кадра. Сцену может создавать и ИИ-агент.

7PNG-спрайты

Открой «Файлы» → «Импорт PNG-спрайта» и используй имя ресурса в sprite(name, x, y, width, height):

function update(dt) {
    clear("#182235");
    sprite("heroSprite", 100, 120, 64, 64);
}

Имя спрайта — имя файла без расширения. Повторный импорт того же файла заменяет спрайт. Если игру делает ИИ, он напишет в чат список изображений, которые нужно импортировать, и их имена.

8Импорт из других файлов (модули)

Создай player.mrr («Файлы» → «Новый .mrr»):

// файл player.mrr
function spawnPlayer() {
    print("Игрок появился!");
}

В main.mrr импортируй имена:

from "player" import spawnPlayer;
from "player" import spawnPlayer, movePlayer;
from "player" import spawnPlayer as spawn;
from "player" import *;

function start() {
    spawnPlayer();
}

«Запуск» всегда выполняет main.mrr. Имя файла можно писать без .mrr и без кавычек. Код модуля выполняется один раз при первом импорте; циклические импорты запрещены. События (update, pointerDown…) должны быть в main.mrr или импортированы в него.

10Редактор на сенсоре, сохранение и ограничения

Всё делается пальцем: панель над редактором вставляет скобки, операторы, шаблоны и функции; пока печатаешь имя — всплывает список дополнений (тапни вариант); после from " подсказываются файлы, после import — функции из файла, после object(" и sprite(" — имена сцены и спрайтов. «📖 Шпаргалка» — поиск по функциям с кнопкой «Вставить».

Используй «⬇ .mrr» для кода и «⬇ Проект» для пакета исходников и ресурсов. Данные хранятся в памяти страницы — экспортируй проект, чтобы не потерять. MrrCode — ограниченный собственный язык, а не полный JavaScript. Выполнение имеет лимит операций для защиты от зависания.

11Визуальный выбор цвета

В редакторе кода можно менять HEX-цвета без ручного ввода. Установи курсор внутри значения вида #70d6ff и нажми 🎨 Цвет. Выбери нужный оттенок — редактор заменит HEX-код прямо в текущем месте.

Поддерживаются цвета #RGB, #RGBA, #RRGGBB и #RRGGBBAA. Также можно дважды тапнуть по HEX-цвету в коде, чтобы открыть выбор цвета.

clear("#101827");
rect(20, 30, 120, 60, "#ff8844");

12ИИ-агент

Кнопка «🤖 ИИ» в шапке открывает агента. Подключение — на тебе:

1. Нажми «⚙ Подключение».
2. Base URL — адрес OpenAI-совместимого API без завершающего /chat/completions (например https://api.openai.com/v1, OpenRouter, Together, локальный LM Studio и т.п.).
3. API-ключ и имя модели (например gpt-4o-mini).
4. «💾 Сохранить» — ключ хранится только в твоём браузере (localStorage), запросы идут напрямую провайдеру.

Напиши задачу, например: «Сделай игру: зелёный квадрат бегает за пальцем и собирает жёлтые монеты, со счётом». ИИ получит контекст проекта: код всех файлов, список спрайтов и сцену. Он может:

• создавать и перезаписывать файлы кода (.mrr), включая модули с импортами;
• работать со сценой как агент — создавать/заменять объекты (прямоугольники, круги, текст);
• сообщать, какие изображения нужно импортировать (имя PNG + описание) — картинки ИИ не генерирует, их импортируешь ты во вкладке «Файлы».

Все изменения применяются сразу и помечаются в чате тегами. Провайдер должен разрешать запросы из браузера (CORS); при ошибке сообщение появится в чате.

13Актуальная документация для ИИ

ИИ получает встроенную спецификацию MrrCode 0.2.0 перед запросом. Она содержит расширение .mrr, ключевые слова и встроенные команды.

ИИ также должен учитывать текущий код проекта: пользовательские переменные, функции и параметры извлекаются из текущего файла и используются как контекст.

14Новые возможности языка 0.2.0+

Массивы: push, pop, splice, shift, unshift, length, join, split, contains, indexOf, slice.

Математика: min, max, clamp, floor, ceil, round, pow.

Строки: trim, upper, lower, startsWith, endsWith, replace.

Типы: typeof.

Массивы используют функции языка, а не JavaScript-подобные методы через точку. Например: splice(items, 2, 1), а не items.splice(2, 1).

15MrrCode 0.2.0
